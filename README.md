# DevOps Lab

Interactive DevOps learning and portfolio project.

## Goal

Build a real application and use it to practice infrastructure automation,
containers, cloud infrastructure, orchestration and CI/CD.

## Infrastructure

### devops-control

- Debian 12
- 1 vCPU
- 2 GB RAM
- 30 GB NVMe
- Stable application and automation host

### devops-lab01

- Debian 12
- 1 vCPU
- 1 GB RAM
- 10 GB NVMe
- Disposable laboratory host
